PRIVATE GAME — 4 HTML + ОБЩИЙ СЕРВЕР ПРОМОКОДОВ

Содержимое:
- index.html — игра (сохранён исходный HTML)
- promo-bot.html — бот/генератор промокодов
- activate.html — страница активации
- admin.html — панель администратора
- server.js — общий HTTP-сервер и API проверки промокодов
- promos.json — база создаётся автоматически

ЗАПУСК (Node.js 18+):
1. Распакуй архив в отдельную папку.
2. Открой терминал в этой папке.
3. Выполни: npm start (или node server.js).
4. Открой http://localhost:8080/
   Админка: http://localhost:8080/admin.html
   Активация: http://localhost:8080/activate.html
   Бот: http://localhost:8080/promo-bot.html

Админка и активация используют общую серверную базу promos.json. Бот отправляет сгенерированные им коды на API сервера. Для работы с других устройств нужно разместить папку на Node.js-хостинге и использовать HTTPS. Не публикуй админку в интернете без авторизации — в этой сборке нет защиты админ-доступа.

ВАЖНО: текущий HTML игры уже обращается к API аккаунтов, инвентаря, матчей и магазина (/api/login, /api/me и т.д.). Этот server.js реализует проверку промокодов и раздачу четырёх HTML, но НЕ заменяет отсутствующий игровой backend для этих остальных маршрутов. Награда промокода пока возвращается как текст награды; начисление валюты в аккаунт игры требует интеграции с игровой базой аккаунтов.
